# Memory Bank

This directory stores concise handoffs between work sessions for the Countdown repository.

## Usage

1. Read `_session_template.md`.
2. Read the newest dated session relevant to the current task.
3. Copy the template to `YYYY-MM-DD-HHmm-short-title.md`.
4. Maintain that single file throughout the conversation.
5. Finish with accurate verification and handoff notes.

Do not use memory files as gameplay specification or implementation authority. Active gameplay rules remain in `docs/gameplay/`.

## Naming

- Template: `_session_template.md`
- Session: `YYYY-MM-DD-HHmm-short-title.md`
- Use a short lowercase kebab-case title.
- Do not create `wf_*` files.

## Maintenance

- Keep sessions concise and factual.
- Never record secrets, access tokens, or personal credentials.
- Do not rewrite old sessions to match later decisions; the active code and documentation remain the source of truth.
- Remove a session only when its handoff value is clearly obsolete and the user authorizes cleanup.
